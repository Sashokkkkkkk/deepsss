## Запросы (файл queries.sql)

### 1. Общее количество забронированных туров в страны Европы
Подсчёт броней, где страна имеет `Континент = 'Европа'` и статус ≠ 'отменено'.

### 2. Итоговая стоимость бронирования для каждой путёвки
```
Цена_за_день × Длительность_дней × (Взрослые + Дети × 0.7)
```
Скидка 30% применяется только к детям.

### 3. Страны, в которые проданы туры на ближайший месяц
Туры с `Дата_начала_тура` в интервале [текущая дата; +30 дней].

### 4. Страны с высокой средней стоимостью тура, но малым числом броней (< 3)
Средняя стоимость тура на человека (цена_за_день × дни) выше средней по всей фирме, и количество броней в страну < 3.

## Как открыть

1. Скачайте `TourAgency.db`
2. Откройте в [DB Browser for SQLite](https://sqlitebrowser.org/) (бесплатно) или DBeaver / DataGrip
3. Выполните запросы из `queries.sql`

Или через командную строку:
```bash
sqlite3 TourAgency.db < queries.sql
```
